# install-runtime Specification

## Purpose

Defines the runtime the kit's installation runs on: a single Python 3 entry point that keeps
the existing CLI, output format, exit codes and write boundaries of the former shell installer.

## Requirements

### Requirement: Запуск установки одним Python-процессом

Установка SHALL запускаться как `python3 install.py` и выполняться интерпретатором Python 3 без
вызова shell-скриптов для собственных шагов. Сторонние библиотеки MUST NOT использоваться: только
стандартная библиотека.

#### Scenario: Локальный запуск из клона
- **WHEN** в клоне kit-а выполняется `python3 install.py --dir <проект>`
- **THEN** устанавливаются те же файлы, что и раньше, и ни один `*.sh` файл установки не запускается

#### Scenario: Только стандартная библиотека
- **WHEN** установка выполняется на машине без сторонних Python-пакетов
- **THEN** установка завершается успешно

### Requirement: Обязательный Python 3

Установка SHALL требовать наличия `python3`; режима без Python MUST NOT существовать. Прежнее
поведение «без `python3` `opencode.json` не правится, а установка идёт дальше» MUST NOT
сохраняться.

#### Scenario: python3 отсутствует
- **WHEN** установка запускается в окружении без `python3`
- **THEN** установка завершается ошибкой с сообщением о нехватке `python3` и ничего не пишет в проект

### Requirement: Сохранение CLI-контракта

Установка SHALL принимать команду `install` (по умолчанию), `--dir <каталог>`, `--with <группы>`
с повтором и списком через запятую, `--dry-run`, `-h`/`--help`. Неизвестный флаг SHALL быть
ошибкой; второй позиционный аргумент SHALL быть ошибкой.

#### Scenario: Справка
- **WHEN** установка запускается с `--help`
- **THEN** печатается справка с версией, флагами и списком доступных групп, код возврата 0

#### Scenario: Неизвестный флаг
- **WHEN** установка запускается с `--nope`
- **THEN** установка завершается ошибкой, называющей флаг и подсказывающей `--help`

#### Scenario: Неизвестная группа
- **WHEN** в `--with` указана группа без каталога в `components/`
- **THEN** установка завершается ошибкой со списком доступных групп и не пишет ни одного файла

### Requirement: Формат вывода

Установка SHALL сохранять прежний формат: заголовок шага `== <текст>`, строки `  OK    `,
`  SKIP  `, `  WARN  ` и `ERROR: `. Строки `WARN` и `ERROR` MUST выводиться в stderr, остальные —
в stdout.

#### Scenario: Успешная установка
- **WHEN** установка проходит на чистом проекте
- **THEN** в stdout есть заголовки шагов и строки `OK`, а stderr пуст

#### Scenario: Предупреждение о пропуске
- **WHEN** установка встретила существующий `AGENTS.md`
- **THEN** в stdout есть строка `SKIP` с причиной, установка завершается успешно

### Requirement: Коды возврата и прерывание

Установка SHALL возвращать 0 при успехе и 1 при ошибке. При получении `INT`, `HUP` или `TERM`
установка MUST удалить свои временные файлы и вернуть 130.

#### Scenario: Ошибка установки
- **WHEN** целевой каталог не существует
- **THEN** установка печатает `ERROR` и возвращает 1

#### Scenario: Прерывание
- **WHEN** установка получает `INT` во время копирования
- **THEN** процесс завершается с кодом 130 и не оставляет временных файлов kit-а в проекте

### Requirement: Неизменённые файлы не перезаписываются

Установка SHALL приводить файлы kit-а к содержимому `components/`, но файл, содержимое которого
совпадает с результатом, MUST NOT перезаписываться, чтобы повторный запуск не менял `mtime`.

#### Scenario: Повторный запуск
- **WHEN** установка запускается второй раз на неизменённом kit-е
- **THEN** содержимое файлов проекта прежнее и диффа в git нет

#### Scenario: Локальная правка
- **WHEN** файл kit-а был изменён вручную и установка запущена снова
- **THEN** файл снова содержит содержимое из `components/`

### Requirement: Границы записи

Установка SHALL писать только внутрь каталога проекта. Домашний каталог и корень файловой системы
MUST быть отвергнуты, целевой симлинк MUST NOT перезаписываться и разыменовываться.

#### Scenario: Домашний каталог или корень
- **WHEN** в `--dir` указан `$HOME`, `$HOME/` или `/`
- **THEN** установка завершается ошибкой и ничего не создаёт

#### Scenario: Симлинк на месте файла kit-а
- **WHEN** целевой путь `.agents/rules/alxmrz_kit_general_rules.md` — симлинк
- **THEN** установка завершается ошибкой, а файл, на который ведёт ссылка, не изменяется

### Requirement: Подсказка об обновлении

В завершающем выводе установка SHALL печатать команду обновления, ссылающуюся на существующий
файл: путь к `install.py` при обычном запуске и повторный запуск `bootstrap.sh`, если клон удалён.

#### Scenario: Обычный запуск
- **WHEN** установка запущена из клона и клон не удаляется
- **THEN** подсказка «Обновить» содержит путь к существующему `install.py`

#### Scenario: Запуск через bootstrap
- **WHEN** установка запущена из клона, который `bootstrap.sh` удаляет после успеха
- **THEN** подсказка «Обновить» предлагает снова запустить `bootstrap.sh`, а не удалённый файл

### Requirement: Автопроверка kit-а

Проверка установки SHALL запускаться как `python3 tests/smoke.py`, работать на одноразовых
каталогах вне репозитория и покрывать прежний набор сценариев: базовая установка, перезапись,
идемпотентность, группы, `commands/` и `agents/`, `AGENTS.md`, `opencode.json`, границы записи,
`--dry-run`, `bootstrap.sh`. Код возврата MUST быть ненулевым при любом провале.

#### Scenario: Все проверки прошли
- **WHEN** выполняется `python3 tests/smoke.py` на неизменённом kit-е
- **THEN** печатается итог со счётчиками PASS/FAIL и код возврата 0

#### Scenario: Проверка провалена
- **WHEN** хотя бы одна проверка не прошла
- **THEN** строка с `FAIL` попадает в вывод и код возврата ненулевой

#### Scenario: Следы вне репозитория
- **WHEN** автопроверка завершилась
- **THEN** временные каталоги удалены, а в `$HOME` и репозитории ничего не создано
