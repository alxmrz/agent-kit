# Proposal

## Why

Правила из `.agents/rules/` не работают сами по себе: OpenCode читает только то, что перечислено
в `instructions[]` файла `opencode.json` (или подключено через `AGENTS.md`). Сейчас установка
печатает пути для ручной вставки, поэтому после `bootstrap.sh` в новом проекте агент не видит
правила kit-а, пока человек не скопирует строку в конфиг. Для `--with php` таких путей два, и
легко забыть один из них.

## What Changes

- Установка дополняет `instructions[]` в `opencode.json` путями правил `base` и **всех**
  выбранных групп — по одному на каждый поставленный файл `.agents/rules/…`.
- Если `opencode.json` нет, он создаётся с одним ключом `instructions`. Существующий файл только
  дополняется: чужие ключи, записи и их порядок, отступ, CRLF и однострочная форма сохраняются.
- Слияние делает новый `lib/merge.py` (python3). Без `python3` или при `opencode.jsonc` файл не
  меняется — печатаются пути для ручной вставки, установка остальных файлов проходит.
- Симлинк `opencode.json` не перезаписывается (как и остальные целевые файлы), установка не падает.
- `--dry-run` показывает план для `opencode.json` и ничего не пишет.
- Изменившиеся гарантии: kit больше не «ничего не правит в чужом» — он владеет только списком
  `instructions[]` и только дополняет его. Чужих файлов по-прежнему не читает и не удаляет.

## Capabilities

### New Capabilities

- `opencode-instructions`: как kit подключает поставленные правила к агенту через `instructions[]`
  файла `opencode.json` — состав путей (base + выбранные группы), создание и дополнение конфига,
  сохранение чужого содержимого и форматирования, идемпотентность, поведение без `python3`, при
  `opencode.jsonc` и при симлинке.

### Modified Capabilities

Нет: `component-install` и `project-agents-file` из незаархивированного изменения
`simplify-install-to-copy` ещё не в `openspec/specs/`, а прежнее требование «правила не попадают
ни в один конфиг автоматически» заменяется новым, а не правится точечно.

## Impact

- `install.sh`: шаг `install_opencode_json` вместо подсказки; `instructions_list` собирает пути из
  `$STATE_DIR/targets`; переменная `AGENTS_WAS_PRESENT` больше не нужна.
- `lib/merge.py`: новый файл, дополнение `instructions[]`.
- `lib/common.sh`: помощник `have` для необязательной зависимости.
- `.github/workflows/ci.yml`: `python3 -m py_compile lib/merge.py`.
- `tests/smoke.sh`: блок про `opencode.json` (создание, дополнение чужого конфига, 4-пробельный
  отступ, CRLF, однострочный JSON, идемпотентность, JSONC, симлинк).
- `README.md`, `AGENTS.md`: гарантии и требования (`python3`).
- Зависимость: `python3` становится необязательной, но рекомендуемой.
